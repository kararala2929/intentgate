# AI StudioからVS Code＆GitHubへのコード反映ガイド（Windows / ZIP上書き方式）

AI Studio上で更新・最適化した最新コードをZIPファイルとしてダウンロードし、Windows上のローカル環境（VS Code）へ安全に上書き反映した上で、GitHubへ送信（Push）する完全ガイドの作成計画です。

- **Confirmed Decision 2（OS環境）**: WindowsエクスプローラーおよびVS Code（Windows版）に特化した操作手順

## 1. Overview & Core Concept

- **目的**: AI Studioで不要コードを削除・最適化した最新状態を、ローカルの作業環境（VS Code）およびリモートリポジトリ（GitHub）へ不整合なく確実に同期させる。
- **対象環境**: Windows 10/11、Visual Studio Code、Git for Windows
- **最重要ポイント**: ローカルのVS Codeプロジェクト内にある既存の `.git` フォルダを誤って削除・破損させず、コードのみを安全に更新して差分として認識させる。

## 2. 反映フローと作業手順（Step-by-Step）

```text
┌─────────────────────────┐
│ 1. AI Studio            │ 右上メニューから「Download Project (.zip)」を実行
└────────────┬────────────┘
             │
┌────────────▼────────────┐
│ 2. Windowsエクスプローラー│ ダウンロードしたZIPファイルを「すべて展開」
└────────────┬────────────┘
             │
┌────────────▼────────────┐
│ 3. ローカル上書き       │ 展開したファイルをVS Codeのプロジェクトフォルダへコピー＆置換
│                         │ ※既存の .git フォルダはそのまま保持
└────────────┬────────────┘
             │
┌────────────▼────────────┐
│ 4. VS Codeで差分確認    │ 左側「ソース管理」タブで削除・変更ファイルを確認
└────────────┬────────────┘
             │
┌────────────▼────────────┐
│ 5. コミット & プッシュ  │ コミットメッセージを入力し「変更の同期（Push）」を実行
└─────────────────────────┘
```

### ステップ詳細

1. **AI Studioからのダウンロード**
   - 画面右上にあるダウンロードアイコン（または「Code / Export」メニュー）からプロジェクトをZIP形式で保存。
2. **ZIPファイルの展開**
   - ダウンロードしたZIPを右クリックし、「すべて展開」を実行。
3. **ローカルプロジェクトへのコピー・上書き**
   - 展開されたフォルダ内の中身を全選択（`Ctrl + A`）してコピー（`Ctrl + C`）。
   - 現在VS Codeで開いているローカルフォルダに貼り付け（`Ctrl + V`）。
   - 「ファイルを置き換える」のダイアログが表示されたら「宛先のファイルを置き換える」を選択。
   - ※ローカルにある `.git` フォルダは上書き対象に含まれないため、これまでのコミット履歴は完全に保護されます。
4. **VS Codeでの差分チェック**
   - VS Codeを開くと、左側の「ソース管理（Gitアイコン）」に青いバッジが表示されます。
   - 今回不要として削除した `MobileGuideModal.tsx` が「D（Deleted）」として、修正したファイルが「M（Modified）」として自動検出されます。
5. **GitHubへのプッシュ**
   - メッセージ欄に `refactor: 不要コンポーネント・未使用importの整理` 等を入力。
   - 「コミット」をクリックし、その後に表示される「変更の同期（Sync Changes）」ボタンを押せばGitHubへ即時反映されます。
